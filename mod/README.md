# Colony Pilot

Colony Pilot is an offline RimWorld 1.6 mod. It automatically assigns colonist work priorities based on relevant skills and colony needs, keeps disabled work types disabled, selects research when needed, creates a potato farm when food reserves are low and no growing zone exists, plans a small roofed shelter when colonists have no usable roofed sleeping area, creates a general stockpile if a home map has none, adds meal and butchering bills when suitable tables are available, manages trade when a trade dialog is opened, can improve eligible faction relations through limited surplus gifts, plans a seed-varied sandbag firing line from the actual home map, and can automatically draft colonists to attack hostile pawns. Firefighting and patient care receive the highest work priority.

This is a local, adaptive rules-based controller, not a remote LLM or a machine-learning model. It samples stored food every six in-game hours, smooths observed per-colonist consumption, and adjusts its food reserve target between 25 and 75 nutrition per colonist based on an estimated 14-day reserve. Farm expansion and trade purchases use that estimate. It also reassesses colony-wide needs hourly: treatment work is promoted when colonists have tendable conditions, growing/cooking are promoted when food is below reserve, and construction is promoted while player blueprints are waiting. Trading raises its medicine reserve when the colony is larger or has injured colonists. Meal targets scale from 20 meals to four per colonist, capped at 120. The farm manager creates a 64-cell potato zone near colonists when food is below the adaptive reserve and no growing zone exists. If food falls below roughly one-third of the adaptive reserve, it can create one additional 64-cell zone. Both zones are labeled and managed by the mod; existing player-created growing zones are left unchanged. If it cannot place sleeping spots in an existing roofed area, the shelter manager plans one 7-by-7 starter room per home map, places a few wall/door blueprints per update, and roofs its 5-by-5 interior only after the perimeter has been built. The stockpile manager leaves existing player stockpiles untouched and creates a default stockpile only when no stockpile exists, sizing it to four cells per colonist (at least 16, at most 64) using nearby roofed cells. Butchering adds one repeat-forever bill when a suitable table is available and no butchering bill exists; humanlike corpses are excluded. Existing bills are left unchanged. Trading runs only when a trade dialog is already open: it buys edible food to replenish the adaptive reserve, buys medicine based on colony size and current treatment needs (5 to 25 units), sells stackable non-food goods above 200 while keeping 100, and tries to retain 500 silver.

Base defense places up to 20 sandbag blueprints around the average position of colony buildings and colonists, in batches of four. It uses the current map's terrain placement checks and `Map.ConstantRandSeed` to choose a repeatable, seed-varied side for each firing line. It only uses the default sandbag fabric, requires the material to already be available, does not remove existing structures, and does not place powered turrets or a complete perimeter. The world seed alone cannot specify a universal base layout: map tile, game version, terrain generation, DLC, and other mods affect the generated map. Colony Pilot uses the map it actually loaded instead of downloading or applying a static community blueprint.

Automatic diplomacy only acts when the player opens a gift-mode trade dialog. For eligible factions that are not hostile and have goodwill below 75, it may gift up to 500 silver market value of eligible stackable surplus, retaining at least 100 of each selected item. It does not change relations directly, declare wars, spend silver, or initiate contact. Gifts consume real colony resources.

Automatic combat selects the closest hostile that each available colonist can attack, drafts those colonists, and starts an attack job. Once no hostile pawns remain, it undrafts only colonists that it drafted itself. It does not coordinate cover, retreat, target priority, or medical care during battle. Automatic combat is enabled by default and takes precedence over the optional pause-on-hostile setting; turn automatic combat off to use that pause behavior instead.

This still does not cover 80-90% of all RimWorld gameplay: the mod does not autonomously manage power grids, a complete defensive perimeter, full production chains, caravans, quests, or strategic combat. Diplomacy is limited to gifts during a player-opened gift dialog. The adaptive controller learns only smoothed food-consumption trends during the current save and responds to a small set of colony needs; it does not train a model or reason about arbitrary game events. The enabled systems are intended as routine colony automation and should be tested in a separate save before use in an important colony.

## Settings

Enable or disable automatic work-priority balancing, research selection, farming, shelter, stockpile creation, production, trading, diplomacy gifts, base-defense planning, combat, and threat pausing in the mod settings. Work priorities and colony planning are evaluated approximately once per in-game hour. Trading and diplomacy use a trade dialog opened by the player and do not initiate contact. Disabling priority balancing stops further automatic changes; it does not restore priorities that were assigned earlier. Threat detection and combat response run about once per in-game second and show one notification per hostile encounter.

## Build and run in VS Code

This project follows the VS Code workflow of [Rimworld-Mods/Template](https://github.com/Rimworld-Mods/Template), adapted for this mod's RimWorld 1.6 references. The upstream template currently targets RimWorld 1.7 and .NET 10, so this project deliberately keeps its .NET Framework 4.7.2 target and uses the installed game's assemblies.

Open this folder in VS Code and use **Terminal > Run Build Task** to build `mod.csproj`. Press **F5** to build and launch the game; enter the directory containing the game's executable when prompted.

The default managed-assembly path is under `Downloads/RimWorld nang caop.com/RimWorld`. If your game is elsewhere, pass `-p:RimWorldManagedPath="C:\path\to\RimWorldWin64_Data\Managed"` to `dotnet build`, or update the default in `mod.csproj`.

The resulting `Assemblies/ColonyPilot.dll` and this mod folder should be placed in the game's `Mods` directory.
